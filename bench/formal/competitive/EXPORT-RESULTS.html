Export gold-form results

Open this file in the same Chrome profile you used for the gold forms. It reads the form data from this page's localStorage and lets you download one combined JSON file.

If no data appears

Chrome may isolate file:// localStorage. In that case, open the gold form, open DevTools (⌥⌘I), go to Console, and run:

copy(JSON.stringify(Object.fromEntries(Object.keys(localStorage).filter(k => k.startsWith('gold-form-')).map(k => [k, localStorage.getItem(k)])), null, 2))

Paste the result into a file, or run the same in the natural form. Then send that file.
